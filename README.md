# Earn2Surf

Платформа заработка на заданиях. Исполнители получают деньги за подписки, регистрации и лайки. Рекламодатели платят за активность.

## Быстрый старт

```bash
cd C:\Users\mvideo\earn2surf
npm install
cp .env.example .env
npm run build
npm start
```

Открой http://localhost:3000
